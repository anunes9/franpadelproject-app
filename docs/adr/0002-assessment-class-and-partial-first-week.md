# One Assessment Class per Module, and a partial first week counts

The parent spec (#6) says "Twice a week: 4 weeks per Module, the 4th being the assessment week". That leaves open whether both Classes of that week are assessments, and how to count a first week that starts mid-week. We decided to keep the Training Plan generator's behaviour:

- **One Assessment Class per Module.** Only the last Class of a Module is an Assessment Class, matching the glossary ("The last Class of each Module"). At twice a week, the earlier Class of week 4 is a regular Class.
- **A partial first week counts as a full week.** The first Class is on the first chosen weekday on or after the start date. That calendar week counts as week 1 of the first Module, even if it holds fewer Classes than the cadence. For example, a Monday and Thursday group starting on a Thursday has one Class in week 1.

## Considered options

- **Both Classes of week 4 as assessments**: rejected. An Assessment Class is where each Player's evaluation of the Module will be recorded. One per Module keeps that to a single place.
- **Not counting a partial first week**: rejected. The Module would gain an extra Class, and the plan would run longer than the methodology's 4 or 6 weeks per Module.
